# 数据字典 v2.1（历史派生输出，仅供追溯）

## 通用约定

| 项目 | 约定 |
|---|---|
| 时间戳 | Unix 秒，浮点数；浏览器和采集端时间分别保留 |
| 设备样本 | `device_sample_number` 为跨 8-bit 包计数展开后的单调样本号 |
| 采样率 | 当前默认 250 Hz，以 `metadata.json` 的实际值为准 |
| 缺失值 | CSV 空字符串；MAT 转换时数值缺失为 NaN，文本缺失为空字符串 |
| 原始数据 | `eeg.csv` 与 `eeg_raw.bin` 永不覆盖、删除或原位滤波 |
| 条件标签 | A/B 是实验条件 weak label，不是瞬时注意真值 |
| 注意标签 | `ON/OFF/AMBIGUOUS/NONE`；只有 probe 回答产生前三类，普通视频窗为 NONE |
| 质量标签 | `GOOD/USABLE/REJECT`；是否可训练另看 `training_eligible` |
| 数据划分 | 按被试、会话、完整 block 或完整 `probe_id` 分组，禁止把同一组窗口拆到不同 fold |

## `eeg.csv`

每个收到的 EEG 样本一行。关键字段：

为兼容旧 CSV 读取器，文件仍保留一个始终为空的 `group_id` 列；v2.1 不再使用其旧的“两 block 一组”含义，分析必须使用 `counterbalance_group` 和 `session_half`。

| 字段 | 含义/单位 |
|---|---|
| `received_timestamp` | 采集端接收时间，Unix 秒 |
| `received_order` | 本 run 内接收顺序，从 0 开始 |
| `device_sample_number` | 展开的设备样本号 |
| `sample_index` | 原始包内 8-bit sample index |
| `sample_time_sec` | 以 run 起点为零的样本时间，秒 |
| `packet_gap_before` | 当前样本前缺失包数 |
| `block_id`, `block_order` | 1–6；非 block 阶段为空/0 |
| `session_half` | 1=Block 1–3，2=Block 4–6 |
| `counterbalance_group` | G01–G12 |
| `video_id` | V1–V6 |
| `condition`, `condition_label` | A 或 B |
| `condition_type` | `focused` / `bbbd_subtraction` |
| `condition_code` | A=0，B=1，非条件=-1 |
| `weak_label` | 当前固定 -1，防止把 A/B 误当注意真值 |
| `phase` | baseline/practice/video/thought_probe/rating/quiz/rest 等 |
| `base_valid_for_training` | 仅表示处于潜在正式视频阶段，不替代窗口 QC |
| `channel_0_raw`, `channel_1_raw` | 24-bit ADC 原始计数 |
| `channel_0_uv`, `channel_1_uv` | 按当前未核实比例尺换算的 µV；设备方确认前谨慎使用 |
| `quality_flag` | 样本级异常，多项以分号组合 |
| `is_formal_experiment` | 1=正式视频有效阶段，0=练习/暂停/问卷等 |
| `stream_segment` | 重连或长缺口后递增，窗口不得跨段 |

## `events.csv`

每个事件一行。`event_name` 与 `event_type` 在 v2.1 新会话中同义。所有关键事件直接包含身份、block、视频、条件、时间和设备样本字段，不依赖解析 `notes`。

关键公共字段包括 `run_id`、`subject_id`、`session_id`、`client_event_id`、`client_id`、`counterbalance_group`、`block_id`、`block_order`、`session_half`、`video_id`、`condition_label`、`condition_type`、`browser_timestamp`、`recorder_timestamp`、`device_sample_number`、`sample_time_sec`、`received_order`、`pause_reason` 和 `alignment_status`。

主要事件族：

- 会话/QC：`session_start/end`、`qc_baseline_start/complete/override`、`qc_status_change`。
- 练习：`subtraction_practice_start/end`、`practice_confirmed`。
- block/视频：`block_start/end`、`condition_prompt_start/end`、`subtraction_start_number_displayed/hidden`、`video_start/end`、`video_pause/resume`。
- probe：`probe_schedule/onset`、`attention_response`、`confidence_response`、`probe_cancelled`。
- 行为：`self_caught`、`rating_start/item_response/end`、`quiz_start/item_response/end`、`rest_start/end`。
- 设备：`eeg_dropout/recovery`、`eeg_recovery_confirmed`、`device_connected/disconnected/error`。

问卷、probe、题目和 override 各有一等字段；`notes` 只保存补充 JSON 或说明。

## `qc.csv`

约每 2 秒一行。包含丢包率、双通道饱和率、RMS、DC 偏移、峰值、70–100 Hz 高频污染比例、平线/恒定值检测、`signal_alive`、状态和消息。按负责人要求，采集阶段没有任何 50 Hz 功率字段。

## 规范化行为表

- `probes.csv`：每个 `probe_id` 一行，合并 onset、attention、confidence、resume；`complete=1` 表示链完整。
- `block_ratings.csv`：每个 block 的 4 个通用评分；B 还含 `subtraction_compliance`、上下限百分比、`subtraction_difficulty`、`reported_final_number`。
- `quiz_responses.csv`：每题一行，含题号、题文、答案索引/文本、正确答案、正误、反应时和时间/样本定位。

## `probe_epochs.csv` 与 `windows.csv`

`probe_epochs.csv` 以 `probe_onset` 对齐样本为锚点，索引 onset 前固定 10 秒，不含 probe 页面。缺链、未对齐、历史不足、缺样、跨 stream segment 或与 probe 页面重叠时标为 rejected 并给出原因，不补齐。

`windows.csv` 的窗口长 4 秒、步长 2 秒。`dataset_membership`：

- `Dataset A`：condition-labelled clean EEG，`probe_attention=NONE`。
- `Dataset B`：probe-confirmed 10 秒 attention epoch，继承 ON/OFF/AMBIGUOUS 和 confidence。

`reject_reason` 可多项组合：`saturation`、`flat`、`missing`、`extreme_amplitude`、`high_frequency_contamination`、`motion`、`motor_event`、`probe_transition`、`non_formal_phase`、`qc_reject` 等。因本次要求移除采集端 50 Hz 测量，不会生成 `line_noise` 原因。

## `session_qc_report.json`

`status` 为 `PASS/WARN/FAIL`。结构检查固定为 6 个 block、24 个完整 probe、6 份问卷、24 道题回答、3 个互异 B 起始数字、3 份 B 专属评分、pause/resume 配对和非空 EEG。会话指标包括总丢包率、最长包缺口、掉线次数/总时长、饱和样本比例、双通道 RMS 中位数和每 block 有效窗口比例。

报告中的 `line_noise_policy.measured_during_acquisition=false` 明确本次例外；离线滤波参数来自同一版本化配置。
