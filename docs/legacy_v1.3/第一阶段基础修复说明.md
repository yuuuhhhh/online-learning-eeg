# 第一阶段基础修复（开发调试）

> 历史变更记录：本文描述第一阶段完成时的系统状态。当前范式已由第二阶段替换为脑内连续减7，现行说明以 README 和《线上学习注意力检测实验设计》为准。

本次只更新数据导出、基础QC、事件记录和结束保存。没有实现减7或thought probe，没有改变A/B条件、口算题型、六Block流程，也没有新增视频齐备、禁止跳Block等正式实验限制。现有开发调试操作继续保留。

更新后请重新启动Python采集程序，并刷新实验网页，使两端使用同一版事件与保存接口。

## CSV与MAT兼容

- 继续支持原有会话目录与主要MAT字段；历史EEG缺少group_id时，沿用按Block推导的处理。qc.csv不存在也可导出。
- 数值字段中的True/False（含大小写变体）映射为1/0，普通数字保持数值，空值保持NaN。缺失整数数据不再强制变成0或导致整数转换失败；缺失原始EEG不进入training_mask。
- events和QC的原始CSV单元格保存在MAT的`csv_text.events`、`csv_text.qc`中。`columns`记录原始列名，`values`为对应文本矩阵。未知文本、空字符串、前导零标识符以及不适合作为MATLAB结构字段的列名仍可核对。
- EEG使用数值数组保存主数据，以控制大文件内存消耗。未知列保存在`csv_text.eeg`；被转换的布尔值、缺失值及不可解析数值的原始单元格保存在`csv_text.eeg_numeric_original`，其中`row_index`为从0开始的CSV数据行索引，另有`column`和`value`。
- MAT先写临时文件，flush/fsync成功后再替换目标文件；失败时保留已有MAT。原CSV不被导出器修改。
- 本次验证覆盖生成的当前/历史格式样例；没有真实历史采集目录可供迁移验收。缺失必要EEG列的任意CSV不等同于受支持的会话格式。

## 基础QC

保留饱和率、50 Hz比例、RMS、丢包率和原有采前/采中策略，增加每通道的：

- `constant_value`：当前窗口是否全部相同；
- `rms_counts`、`near_zero_rms`：在原始ADC计数上计算去均值RMS，接近数值零的阈值为1e-6个ADC计数；
- `longest_unchanged_sec`：连续相同采样值的最长时段；
- `invalid_flatline`：足够样本中恒定/接近零，或连续至少2秒不变。

这些量同步写入qc.csv和MAT。检测不使用未校准的µV幅值作绝对准入阈值；1个ADC计数量级但持续变化的模拟信号可以通过。低幅信号若被硬件量化为完全不变，与其他恒定无效数据无法仅凭软件区分。

## 事件身份和时间

新记录的`schema_version`为1.4，这是数据格式版本，不代表实验方案已升级到v2.1。

每个run使用独立UUID，同时保留原来的输出目录命名。事件显式携带run、subject、session、block和客户端事件ID；明显不匹配的run/session被拒绝。历史缺少身份字段或使用旧run目录名的事件仍可接收，但标记为`legacy_partial`。

网页从/session请求估计两端时钟偏移，优先采用最近一分钟内往返时间较小的样本。事件保存以下字段：

| 字段 | 含义 |
|---|---|
| event_timestamp | 事件发生时间；新网页使用校正后的Unix时间 |
| received_timestamp | Python收到该事件的时间 |
| timestamp_source | 校准网页时间、旧ISO时间或服务端回退时间 |
| client_timestamp / client_monotonic_ms | 浏览器原始时间和单调时钟读数 |
| clock_offset_sec / clock_round_trip_ms | 使用的偏移估计和测得往返时间 |
| received_order | 保留旧语义：接收事件时已记录的EEG样本数 |
| eeg_received_order | 按发生时间关联的EEG行号，从0开始 |
| eeg_sample_number / sample_time_sec | 关联样本的计数及采样时间坐标 |
| eeg_stream_segment | 关联样本所属的连续数据段 |
| alignment_error_ms | 关联EEG接收时间减事件发生时间，带正负号 |
| alignment_status | 主机接收时间近邻关联，或无数据/超出关联范围 |
| context_matches_current / state_applied | 来源Block是否匹配当前状态、是否实际推进在线流程 |

事件位置根据已接收EEG的主机时间索引查询。离最近样本超过250ms时，关联位置留空并明确标记；该阈值是最大搜索范围，不是已验证的时间精度。延迟事件保留来源Block，不会被自动改记到当前Block；过期状态事件不会倒退在线状态。

BLE设备没有提供经过验证的硬件采样时间戳，因此此关联仍受BLE批量传输和HTTP时钟估计误差影响。它不等价于硬件触发同步。历史事件中没有原始发生时间的信息无法补造；旧ISO时间标记为未校准。

重连或长接收间断会产生新的`stream_segment`，避免把设备序号复位当成大量丢包。之后的`sample_time_status=counter_elapsed_ambiguous`表示8位包序号不能恢复完整掉线时长。后续切窗应使用行号、段号和时间信息，不能跨断线段拼接窗口。

实时EEG的phase/weak_label仍在事件被收到时更新；本阶段没有对历史CSV标签进行离线重写。后续窗口处理应优先使用上述事件发生时间及关联字段，并检查时钟与关联质量。

## 结束保存

关闭采集窗口后，HTTP服务继续运行；网页暂停产生新事件，发送已有队列及最后标记，再确认队列排空。后端核对最后事件确实存在，并对CSV/BIN/QC执行flush和fsync，然后关闭记录文件、导出MAT，最后写最终metadata状态。

- `complete`：实验流程完成，保存和导出成功；
- `stopped`：开发调试或提前结束，数据已保存；
- `saved_with_unresolved_events`：存在未通过校验的事件，原始内容已额外写入`pending_browser_events.json`，需要核对；
- `export_failed`：MAT导出失败，保留CSV及窗口，可重试。

网络错误保留队列并重试。被语义校验拒绝的事件保留本地副本；属于当前run的副本在结束时另存恢复文件，不混入有效events数据。属于旧run的待发送事件仍保留在浏览器备份/JSON导出中，不自动归入新run。

若已连接网页在15秒内无法确认队列，取消本次关闭并保留会话，恢复网页后可重试。请在采集端保存完成前保持相关网页打开。浏览器/操作系统被强制结束、存储设备故障不能保证尚未送达的数据落盘。
