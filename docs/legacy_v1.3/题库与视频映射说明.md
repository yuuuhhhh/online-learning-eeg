# 线上学习 EEG 一体化实验系统：最终题库版

## 题库来源

本版专题测验严格采用：

`世界文明史课后单选题(1).docx`

每个专题 3 道四选一单选题，答案与该文件一致。

## 已确认的六个专题

1. 埃及金字塔
2. 中东文明
3. 古代印度文明
4. 古代希腊文明
5. 古代罗马文明
6. 美洲文明

- task_a古埃及.mp4 → 埃及金字塔
- task_b中东文明.mp4 → 中东文明
- task_c古代印度文明.mp4 → 古代印度文明
- task_d古希腊文明.mp4 → 古代希腊文明
- task_e古罗马文明.mp4 → 古代罗马文明
- task_f美洲文明.mp4 → 美洲文明

## 使用方法

1. Chrome 或 Edge 打开 `index.html`。
2. 点击“选择6个视频文件”。
3. 一次选中六个 MP4。
4. 六项视频匹配均显示绿色“✓”后开始实验。
5. 每个 Block 完成后立即导出 CSV 和 JSON。
