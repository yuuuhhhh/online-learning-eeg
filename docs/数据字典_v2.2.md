# 原始采集数据字典 v2.2

## 权威原始文件

- `eeg_raw.bin`：实际接收顺序拼接的 33-byte BLE 包，不补包、不改写。
- `eeg.csv`：每个实际接收包一行；`channel_0_raw`、`channel_1_raw` 为 signed 24-bit ADC counts。
- `events.csv`：标签时间的权威来源。每行有唯一 `event_id`、主机 `recorder_timestamp`、可用时的 `device_sample_number`、`alignment_status` 和 `source_client`。

`eeg.csv` 中的 `packet_gap_before` 只记录缺失数，不产生填充行；重复包保留并以 `quality_flag=duplicate_index` 标记；重连或长断点后 `stream_segment` 增加。

`channel_N_uv = channel_N_raw * eeg_scale_uv_per_count`。换算公式和 `verification_status` 写入 `metadata.json`；未完成硬件确认时不得把该字段当作已验证真实 µV。

## 采集状态与标签表

- `acquisition_qc.csv`：数据龄、样本数、估计采样率、丢包、重复包、饱和和平线等现场状态，只用于发现采集故障。
- `probes.csv`、`block_ratings.csv`、`quiz_responses.csv`：从 `events.csv` 规范化出的原始行为回答，不包含 EEG 窗口。
- `session_acquisition_report.json`：会话结束、采集时长、样本/包数、丢包、重复包、断流、Block/probe/问卷/题目完整性、未对齐事件和原始哈希。
- `checksums.sha256`：`eeg.csv` 与 `eeg_raw.bin` 的 SHA-256。
- `session_raw.mat`：可选容器，只含连续原始 EEG、事件、行为标签、采集状态和元数据。

## 明确不存在的采集输出

新会话不生成窗口、epoch、预处理副本、伪迹结论、训练掩码、`training_eligible` 或 `GOOD/USABLE/REJECT` 标签。历史文件若存在，只能作为 legacy derived output 追溯。
